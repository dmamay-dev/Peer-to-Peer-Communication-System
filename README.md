# Peer-to-Peer Communication System на Rust

Навчальна децентралізована P2P-система поверх TCP. Кожен процес одночасно є сервером і клієнтом.

## Можливості
- власний JSON-протокол з одним повідомленням на рядок;
- `hello`, `chat`, `peer_list`, `ping`, `pong`;
- підключення нових вузлів і обмін списками адрес;
- прямі та широкомовні повідомлення;
- структуроване логування через `tracing`.

## Запуск
```bash
cargo build
RUST_LOG=info cargo run -- node-a 127.0.0.1:7001
RUST_LOG=info cargo run -- node-b 127.0.0.1:7002 127.0.0.1:7001
RUST_LOG=info cargo run -- node-c 127.0.0.1:7003 127.0.0.1:7001
```

## Команди
```text
/peers
/connect 127.0.0.1:7003
/send 127.0.0.1:7002 Привіт, node-b!
/broadcast Вітаю всіх!
/quit
```

## Перевірка
```bash
cargo test
```

## Протокол
Повідомлення кодуються в JSON та завершуються `\n`. Приклад:
```json
{"type":"chat","from":"node-a","text":"Привіт"}
```

## Обмеження навчальної версії
Немає шифрування, автентифікації, NAT traversal, автоматичного повторного підключення чи гарантованої доставки. Для використання поза локальною мережею ці механізми потрібно додати.
